# Единый сценарий проверки интерфейса

Для каждой версии: открыть через HTTP, перед каждым независимым сценарием перезагрузить страницу.

| Проверка | Действия и ожидание |
|---|---|
| T1 | 3 исходные задачи; всего 8 ч, готово 2 ч, 25% |
| T2 | Отметить Практику: готово 6/8 ч, 75%; снять отметку: 25% |
| T3 | Активные: Практика и Повторение, прогресс 25%; Готовые: Чтение, прогресс 25% |
| T4 | Пустое название, пробелы, пустые часы, -1, 0.7, 24.5: задача не добавлена, ошибка возле поля, введённые значения сохранены |
| Границы | 0.5 и 24 добавляются; новая задача активна |
| T5 | Удалить все: 0 ч, 0%, понятное пустое состояние; затем добавить новую задачу |
| 390 px | Нет горизонтального скролла, подписи и кнопки видны, форма и список работают |
| Безопасный текст | Название <img src=x onerror=alert(1)> отображается текстом, а не HTML |

Результаты и подтверждения фиксируются отдельно для direct и with-spec. Браузерные проверки не считать выполненными по результатам node:test.

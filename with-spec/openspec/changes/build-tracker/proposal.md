# Why
Нужен автономный мини-трекер учебных задач на неделю по brief.md, вариант B. Спецификация фиксируется до реализации для независимого сравнения подходов.

## What Changes
- Добавить форму создания задачи, переключение done и удаление.
- Валидировать название и часы; показывать ошибки возле полей без потери ввода.
- Показывать взвешенный по часам прогресс, суммарные и выполненные часы.
- Добавить фильтры «Все», «Активные», «Готовые» и интерфейс на 390 px.
- Реализовать согласованный контракт чистых функций domain.mjs и проверить T1–T5.

## Capabilities
### New Capabilities
- `tracker`: задачи, валидация, метрики, фильтры и доступный адаптивный интерфейс.

### Modified Capabilities
Нет.

## Impact
Файлы приложения: index.html, styles.css, app.mjs, domain.mjs. Общие тесты tests/acceptance.test.mjs остаются без изменений. Запуск через статический HTTP-сервер; без сборки, библиотек, CDN, API, аккаунтов и сервера приложения. localStorage не используется; перезагрузка восстанавливает пример.
